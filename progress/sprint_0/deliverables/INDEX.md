updated during Sprint 0. The root project artifacts remain the sources of truth;
this directory preserves the Sprint 0 delivery snapshot.

- `README.md` is the accepted product vision.
- `BACKLOG.md` and `PLAN.md` are the tailored lifecycle roadmap.

  complete before Sprint 2.

  local RUP procedure and generic-bootstrap refinements.

Sprint-internal evidence, including `sprint_0_roadmap_proposal.md`, remains in
the parent `progress/sprint_0/` directory and is not duplicated here.
